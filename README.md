# Vコンメモ

動画や音声を止めて、画面に手書きでメモを入れるツールです。
Vコン（ビデオコンテ）の下書きをブラウザだけで作れます。

公開ページ: https://3208noname-arch.github.io/Vcon-Memo/

## 使い方

1. ページを開き、「＋ 新規プロジェクト」から動画か音声のファイルを選びます。
2. 動画を止めて画面にペンで書くと、止めた時刻に新しいメモができます。
3. メモは次のメモの時刻まで出続けます。
   設定で「書いたコマだけ」「書いたコマから指定秒数」にも変えられます。
4. 「メモのコマで静止」をオンにすると、再生と音声は止めずに画だけをメモのコマで止めます。

シークバーの赤い印がメモです。
印を左右にドラッグするとメモの時刻を動かせます。
印と印の間には、メモが出ている秒数を表示します。

## 手元のファイルはどこにも送りません

- 動画や音声はお使いの端末の中で再生するだけで、サーバーへは送りません。
- メモと一覧はお使いのブラウザの中に保存します。
- 「動画・音声を、この端末のブラウザに残す」をオンにすると、選んだファイルもブラウザに残り、次から選び直さずに開けます。設定で切れます。

## 主な機能

- ホーム画面（新規プロジェクト、最近のプロジェクト、並び替え）
- ペンの色の選び方（丸形、四角、色見本のみ）と、HEX・RGB・HSL・HSB での値の確認と入力
- メモの透明度、秒送りの幅、再生速度
- コマ送り、秒送り、前後のメモへの移動
- 戻す・やり直す、コピー・貼り付け、消しゴム
- タブレットで手のひらや指が触れても描かないようにする設定（ペンだけで描く、など）
- メモの書き出しと読み込み（`.vcon.json`）
