# Vコンメモ

動画や音声を止めて、画面の上に手書きでメモを入れるツールです。
Vコン（ビデオコンテ）の下書きを、ブラウザだけで作れます。

## 使い方

1. ページを開き、「＋ 新規プロジェクト」から、動画か音声のファイルを選びます。
2. 動画を止めて、画面の上にペンで書きます。止めた時刻に、新しいメモができます。
3. メモは、次のメモの時刻まで出続けます。
   設定で、「書いたコマだけ」「書いたコマから指定秒数」にも変えられます。
4. 「メモのコマで静止」をオンにすると、再生と音声は続けたまま、画だけをメモのコマで止めます。

シークバーの赤い印がメモです。
印を左右にドラッグすると、メモの時刻を動かせます。
印と印の間には、メモが出ている秒数が出ます。

## 手元のファイルは、どこにも送りません

- 動画や音声は、お使いの端末の中で再生するだけです。サーバーへは送りません。
- メモと一覧は、お使いのブラウザの中に保存します。
- 「動画・音声を、この端末のブラウザに残す」をオンにすると、選んだファイルもブラウザの中に残します。次から、選び直さずに開けます。設定で切れます。

## 主な機能

- ホーム画面（新規プロジェクト、最近のプロジェクト、並び替え）
- ペンの色（丸形・四角・色見本のみ。HEX、RGB、HSL、HSB で値を確認・入力）
- メモの透明度、秒送りの幅、再生速度
- コマ送り、秒送り、前後のメモへの移動
- 戻す・やり直す、コピー・貼り付け、消しゴム
- タブレットで、手のひらや指が触れても描いてしまわない入力の設定（ペンだけ、など）
- メモの書き出し・読み込み（`.vcon.json`）
